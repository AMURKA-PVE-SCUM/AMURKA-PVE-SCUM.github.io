# AMURKA 2.0 — общая концепция

> **Каждая страница отвечает на один конкретный вопрос игрока.**

**«Что это?»** → Главная / Сервер

**«Что здесь есть?»** → Возможности

**«Что сейчас происходит?»** → Live

**«Кто лучший?»** → Статистика

**«Как играть?»** → Старт

**«Что можно/нельзя?»** → Правила

**«Что умеет DOMO?»** → DOMO

И т.д.

# Админка

И вот это я бы тоже заложил сразу.

Не редактировать HTML вручную.

Сделать:

```text
AMURKA ADMIN

Dashboard

SERVER
ONLINE
37 / 100

NEWS
[ + NEW ]

EVENTS
[ + NEW ]

MODS
[ + NEW ]

POI
[ + NEW ]

[ MODERATION ]

```

То есть ты заходишь в админку и можешь:

**добавить новость → она появляется на главной и в /news/**

**добавить событие → оно появляется на главной + /events/ + LIVE**
